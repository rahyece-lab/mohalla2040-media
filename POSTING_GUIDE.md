1. Open https://github.com/rahyece-lab/mohalla2040-media/tree/main/daily/<today's date YYYY-MM-DD>/ and read POSTS.md.
2. Download the listed videos and covers (raw.githubusercontent.com links) to the Downloads folder.
3. For each post whose time has come (or the owner says "now"), in the owner's own logged-in Chrome:
   - Instagram (instagram.com > Create > Reel): upload the video, set the cover image, paste the caption exactly, share. Then post the "First comment" under it.

4. Never change captions, never tick any AI-generated label, never post anything not in POSTS.md, never touch account settings or passwords.
5. Report back the live links.
